.ts-section--alt (re-anchor → --ts-this-bg-bright of body)

/ 02 — ALT

Alt — contrast-driven, no static surface

The frozen .ts-section--alt used a static --ts-bg-1 literal. The migrated form mixes the primitive --ts-bg-body toward --ts-tone-contrast in oklab — contrast-driven and theme-agnostic (no [data-theme] branching). Auto-nesting is DEFERRED (Wave 1 delivers 2 of 3 owner-ruled properties; the third needs @property-typed --ts-this-bg in the engine — see decisions/engine-followup-property-typed-this-bg.md).

Nested .ts-section--alt (auto-nesting DEFERRED — renders identical to single alt)

Honest reporting: this nested alt re-reads the same --ts-bg-body primitive that the outer alt does, so the surface is identical — matches frozen idempotency. True auto-nesting (each level stepping further toward contrast) requires @property-typed --ts-this-bg in the engine to break the CSS variable cycle the worker hit. Tracked in decisions/engine-followup-property-typed-this-bg.md.
