T9 · --ts-nav-collapse-at is the single source of truth

/* Token (component scope, override per-project) */
--ts-nav-collapse-at: 720px;

/* ts-nav-v2.js reads it → creates matchMedia → toggles class */
var mq = window.matchMedia("(max-width: " + collapseAt + "px)");
nav.classList.toggle("ts-nav--collapsed", mq.matches);
nav.setAttribute("data-breakpoint-synced", "1");

/* CSS: .ts-nav--collapsed wins; @media (868px) fallback is gated */
.ts-nav-fixed:not(.ts-nav--static).ts-nav--collapsed { ... }
@media (max-width: 868px) {
  .ts-nav-fixed:not([data-breakpoint-synced]) { ... }
}

T8 · Transparent mode — separated from at-top signal

.at-top = scroll signal only (JS). .ts-nav--transparent = opt-in feature. Both are required for the transparent effect (live nav above demonstrates this — scroll to see it change). 

/* SIGNAL — no visual change */
.ts-nav-fixed.at-top {
  .ts-back_top-nav .ts-icon { transform: rotate(270deg); }
}

/* FEATURE — opt-in, active only when also .at-top */
.ts-nav-fixed.ts-nav--transparent.at-top {
  --ts-nav-bg-alpha: 100%;
  --ts-nav-border-alpha: 100%;
  --ts-nav-text-alpha: 0%;
  &::before { backdrop-filter: none; }
}

T11 · Promo banner — clean rebuild

--ts-page-top-offset replaces all CRAZY_FIX_RULES. One coordination token drives nav top + first-section padding. Dismiss the banner above to see the offset update. 

/* body:has() computes the offset — no JS needed */
:root { --ts-page-top-offset: var(--ts-topbar-h, 58px); }
body:has(.ts-promo-banner:not(.ts-dismissed)) {
  --ts-page-top-offset: calc(var(--ts-topbar-h) + var(--ts-promo-banner-h));
}

/* Nav sits below banner */
body:has(.ts-promo-banner:not(.ts-dismissed)) .ts-nav-fixed {
  --ts-nav-offset: var(--ts-promo-banner-h);
  top: var(--ts-nav-offset);
}
