## MANDATORY CONTEXT — READ BEFORE ANY AGENT IS DISPATCHED

### What Toolskin is
A single CSS file that turns any website, web app, or WordPress theme into a
complete design system. Change one variable — the whole site re-themes. No
build tools. No Node. No framework lock-in. Token-driven, derivative-math-driven.
240+ values cascade from one token. OKLCH auto-contrast. WCAG AA built in.
Zero dependencies. Framework-independent. Built by a solo founder.

### What this operation is for
AutomaticCSS (ACSS) occupies an adjacent niche — WordPress-only CSS framework
with a GUI dashboard. Their execution is not exceptional. Their communication,
positioning, and sales decisions ARE. This operation extracts every decision
they made, classifies it against Toolskin's reality, and converts findings
into a strategic execution system.

The goal is NOT to compete with ACSS. The goal is to:
1. Use their months/years of market decisions as free research
2. Identify the category gap (they are tool-bound; Toolskin is universal)
3. Avoid their strategic mistakes
4. Build a fundamentally different and superior proposal
5. Accelerate the publishing phase without losing direction

### Toolskin's strategic position (validation filter for every finding)
- Solo founder capacity — no team, no ad spend, no existing audience
- ~200 followers — no paid base
- Primary segments: Vibecoder designers (primary), Frontend/CMS devs (secondary)
- All other segments deferred
- Revenue path: Services → Premium Bundles → Toolskin Pro WP
- Day 30 base case: $1,800 – $4,000 cumulative
- Kill-switch: Day 14 = 1 booked call minimum; Day 30 = $1.5K minimum

### Classification filter (applied to every extracted finding)
- REUSABLE: High-value pattern transferable to Toolskin's model
- CONTEXTUAL: Works only for ACSS's specific setup (scale, audience, WP-only)
- TOXIC: Reinforces platform dependency, low-skill targeting, or superficial UX

### Positioning boundary (hard constraint on all decisions)
Toolskin must NOT be positioned as:
- A better version of AutomaticCSS
- A beginner-friendly tool
- A template or UI kit product
- A WordPress-specific plugin
- An ease-of-use shortcut

Toolskin IS:
- A universal, system-level interface layer
- A derivative math engine for design systems
- A cross-platform, framework-independent stylesheet
- An AI-implementable design system (any agent can use it correctly)
- A production engine for delivering client work faster than competitors

### STEP 2 — FILTER SIGNAL FROM NOISE

Every extracted finding must be classified. No finding is valid without
a classification.

Classification criteria:

```
REUSABLE — Transfer to Toolskin's model
  Conditions: works for a solo operator, works without existing audience,
  works for advanced/technical buyers, does not require platform dependency

CONTEXTUAL — Works only for ACSS's specific setup
  Conditions: requires Kevin Geary's personal brand reach, requires large
  community, requires WordPress ecosystem relationships, requires team

TOXIC — Reject immediately
  Conditions: reinforces platform lock-in, targets beginners primarily,
  implies ease-of-use as main value, competes on templates or component counts,
  requires scale to execute, pulls toward superficial UX

Anything that reinforces:
  - platform dependency → TOXIC
  - low-skill targeting → TOXIC
  - superficial UX → TOXIC
  - "just set it and forget it" framing → TOXIC
  - "no coding required" positioning → TOXIC
```
