ts-btn · smart button system v3

Consolidates the legacy ts-button.css on the refactored Toolskin platform. Color flows through the --ts-this-bg engine (oklab-safe, no purple), surfaces optionally pull from the v3 gradient library, and every dimension derives from a single base knob via ratio tokens. No static pixel sizes, no duplicated state blocks, no hardcoded colors — drop a .ts-btn anywhere and the whole system retunes from the inherited font-size up.

1 · The sizing engine

One unitless base, six ratios, every dimension follows the original recipe verbatim. --ts-btn-base defaults to 45 (a number, not px); the chain multiplies by 1px at the end so any integer slider can drive the whole system. Override --ts-btn-base on any ancestor to retune a subtree; override --ts-btn-scale on a single button to nudge just that one.

The chain

/* one knob — unitless */
--ts-btn-base:  45;
--ts-btn-scale: 1;
--ts-btn-size:  calc(var(--ts-btn-base) * var(--ts-btn-scale));

/* every dimension derives — × 1px happens at the end */
--ts-btn-h:         calc(size × --ts-btn-h-ratio     × 1px);
--ts-btn-pad-x:     calc(size × --ts-btn-pad-x-ratio × 1px);
--ts-btn-pad-y:     calc(pad-x × --ts-btn-pad-y-ratio);
--ts-btn-fs:        calc(size × --ts-btn-fs-ratio    × 1px);
--ts-btn-icon-size: calc(fs   × --ts-btn-icon-ratio);
--ts-btn-radius:    calc(size × --ts-btn-radius-ratio × 1px);
--ts-btn-counter-size: calc(fs × --ts-btn-counter-ratio);
--ts-btn-border-w:  max(1px, size × --ts-btn-border-ratio × 1px);
--ts-btn-letter:    calc(fs × --ts-btn-letter-ratio);

Live dimensions · default ratios

--sm · scale 0.84 → h ≈ 34px · fs ≈ 9px

6 · Gradient skins · lush mode

Opt-in only — every skin reads its colors from the v3 gradient library, which is itself parametric off --ts-this-bg and --ts-grad-tint. Add a single .ts-lush on any wrapper and the children get gradient surfaces without touching the variant classes.

7 · Button groups

Siblings share a single border edge. Hover/focus auto-promote the active button via z-index so the highlight stays visible across the seam.

9 · Markup contract

SmartButton DOM target — icon, text span, optional counter/spinner. The component works without the span, but giving every button a .ts-btn-text wrapper lets icon spacing, counters, and loading states stay aligned across variants. 

<!-- primary, icon + text + counter -->
<button class="ts-btn ts-btn--primary ts-btn--lg">
  <i    class="ts-icon fa-solid fa-bell"></i>
  <span class="ts-btn-text">Notifications</span>
  <span class="ts-btn__counter">12</span>
</button>

/* retune the whole system from any ancestor */
.sidebar   { --ts-btn-base: 13px; }      /* tight controls   */
.hero      { --ts-btn-base: 20px; }      /* prominent CTAs   */
.toolbar   { --ts-btn-base: 12px;
              --ts-btn-radius-ratio: .25; } /* squarer corners  */

/* lush gradient mode — no class changes on the buttons */
<div class="ts-lush"> /* …buttons… */ </div>
