/ 07

The agent workflow.

From "build me a landing page" to "shipped" in under 40 minutes. No invention. No doubt.

1

Classify the task

PAGE · CARD · TYPE · COLOR · LAYOUT · COMPONENT · ENFOLD · REVIEW. State the class in one sentence before doing anything else.

2

Open ≤ 2 references

Each task class has a fixed entry point. If you need a third reference, you misclassified — re-classify.

3

Walk the decision trees

Font? Step? Padding? Mode? Each has a tree in SKILL.md §4. Walk it out loud. Show the path you took.

4

Build with locked systems

Color via generate-colors.js. Type via the 1.200 ladder. Space via 8pt grid. Layouts via three primitives.

5

Verify

node scripts/generate-colors.js + node scripts/audit-design.mjs <file>. Hard fails halt the build.

6

Hand off

Report: class chosen, recipes used, tokens introduced (ideally zero), audit score, and the manual checklist.

Total time for a competent agent: 20–40 minutes for a landing page. Taking longer means inventing instead of looking up — stop and re-read the skill.
