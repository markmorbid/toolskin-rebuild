§01 The Product

What is Toolskin, in one minute.

A single CSS file that turns any website, web app, or WordPress theme into a complete design system. Change one variable — the whole site re-themes. No build tools. No Node. No framework lock-in.

AudienceValue
DevelopersToken-driven CSS with derivative math. Change --ts-accent-h, the entire theme regenerates via color-mix() and clamp(). Drop one stylesheet, ship anywhere.
DesignersFigma variables that actually render in production. One token at the top, 240+ derived values cascade through every component automatically.
Agencies50 unique client brands from one stylesheet. Token-swap delivery in days, not weeks.
Non-technical buyersA free design engine any website can use to look professional. Premium features and bundled solutions are paid.

Technical specs: 10,000+ lines of CSS · OKLCH auto-contrast · WCAG AA built in · Zero dependencies

§02 Market Reality

The market changed in 2025. Plan accordingly.

What died

Tailwind UI revenue collapsed 80%. 75% of their engineering team was laid off. Cause: AI generators (v0, Cursor, Lovable, Bolt) made one-time-purchase component libraries obsolete.

"Tailwind is bigger than ever. Revenue is down 80%." — Adam Wathan, founder · GitHub, 2025

What still makes money in 2026

  • Enterprise contracts with SLA + support
  • Hosted services with recurring infrastructure
  • Education, certification, books
  • High-margin custom services
  • Niches AI doesn't serve (WordPress GUI users)
Implication for Toolskin: Selling premium CSS components as a primary revenue model is structurally weaker than 18 months ago. The path is services first, productized later. Toolskin's value isn't the components — it's using them as a production engine to deliver client work faster than competitors.

Sources: Sacra · Contrary Research · Tailwind Labs founder statements · Yahoo Finance

§10 Portfolio & Case Study Strategy

Mockups become credibility. Honestly.

Current assets: 4 mockups (Higgsfield, YouTube Studio, Suno, userscript toolpanes) + Claude Design experiments. None are paid client work.

These are reframable as design system explorations — which is honest, defensible, and resonates with the Awwwards-tier audience more than fake client logos.

Each case study page contains

  • Hero — before/after screenshots
  • The problem (existing UI characterization)
  • The Toolskin solution (token map, how it was applied)
  • Technical detail (hours, tokens used)
  • Live demo — interactive token swap
  • Disclaimer: design exploration, not paid work
The "founding customer" framing:
"What I have is design system explorations on real-world UI surfaces. You'd be the first paid project — which means founding-customer pricing and direct access to me as the system's author."
Use for first 3–5 service contracts. Drop once real delivered work exists.
Claude Design experiments pitch (Vibecoder Designer segment):
"Here's what AI generates against Toolskin's token system. Notice how it stays on-brand even though no human styled these — because the tokens drive everything."
Use the dev-ide demo and ops dashboard as Exhibit A in cold outreach.
