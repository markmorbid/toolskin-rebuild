<link rel="stylesheet" href="toolskin.css">

<!-- 2. surface engine — derives state + border + dim from --ts-this-bg -->
<link rel="stylesheet" href="toolskin-this-bg-v2.css">

<!-- 3. gradient library — derives every gradient from --ts-grad-tint -->
<link rel="stylesheet" href="toolskin-gradients-v3.css">

The fix that started this

v1's --ts-this-bg-focus mixed in oklch. Between a blue-tinted dark neutral and the orange accent, the short hue arc passes through magenta — that's the purple bug. v2 fixes it with three layered moves: mix in oklab, use a desaturated --ts-tone-accent-tint, and drop the percentage from 20% to 8%.

✗ v1 — oklch wash, 20%
color-mix(in oklch, --ts-this-bg, --ts-accent 20%)
→ hue wraps via magenta → reads as purple
✓ v2 — oklab tint, 8%
color-mix(in oklab, --ts-this-bg, --ts-tone-accent-tint 8%)
→ no hue path, reads as a warm focus tint

Token quick reference

These are the high-level inputs. Override on any scope to retune a subtree. Full list in the source files and in GRADIENTS.md.

Surface engine

--ts-this-bg
base surface for this scope
--ts-tone-contrast
achromatic "lighten toward" anchor
--ts-tone-floor
achromatic "darken toward" anchor
--ts-tone-accent-tint
desaturated brand tint used for focus / selected
--ts-mix-perc-focus
focus tint strength (default 8%)
--ts-mix-perc-hover
hover lift (default 22%)
--ts-mix-perc-active
border-active tint (default 32%)

Gradient library

--ts-grad-tint
color the whole library pulls from
--ts-grad-tint-2/-3
secondary / tertiary tints for aurora
--ts-grad-peak
global alpha ceiling (default 0.55)
--ts-grad-intensity
relative multiplier (0–1.5)
--ts-grad-angle
linear/sweep axis (default 136deg)
--ts-grad-pos-off-tl
off-canvas anchor point
--ts-grad-halo-a-N
per-curve alpha at stop N (1–8)

Three recipes you'll use

All three follow the same shape: set --ts-this-bg + --ts-grad-tint + a peak, then drop the utility class.

/* — Atmospheric hero — */
.hero {
  --ts-this-bg:        var(--ts-bg-1);
  --ts-grad-tint:      var(--ts-accent);
  --ts-grad-peak:      0.65;
  background: var(--ts-grad-stack-editorial);
}

/* — Feature card — */
.feature {
  --ts-this-bg:        var(--ts-bg-2);
  --ts-grad-tint:      var(--ts-accent);
  --ts-grad-peak:      0.55;
}
.feature        { background: var(--ts-grad-stack-aurora-on-bg); }
.feature:hover  { --ts-grad-peak: 0.7; }

/* — Quiet section plate — */
.section {
  background: var(--ts-grad-plate), var(--ts-bg-body);
}
