Toolskin · component verification harnesses

Self-contained portable copy of the Phase 2 component sandbox. Each tile opens a verification harness for one component family. All CSS, tokens, and engine layers ship inside assets/ — only Google Fonts is fetched from the web. Every harness shares one scaffold (assets/css/next/harness.css) and the same live Variant Tester (bottom-right) for cross-validating surfaces, gradients, accents, type, radius, and inputs.
