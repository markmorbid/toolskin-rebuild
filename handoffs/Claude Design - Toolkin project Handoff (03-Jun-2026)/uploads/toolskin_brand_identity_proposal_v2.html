Brand Brief

Toolskin — Identity Foundation

Toolskin is a CSS design system built for precision engineers and pragmatic developers. It isn't a pretty component library — it's infrastructure with aesthetics. The brand identity must communicate: engineered control, raw accuracy, zero decoration overhead.

Target Audience

WordPress power users · Toolpanel / automation engineers · UI framework builders · SatSea product users. Technically fluent, opinionated, impatient with fluff.

Tone Directive

Industrial-precision meets aggressive orange. Like a professional tool with a sharp edge — a Stanley blade, not a Swiss watch. Dark-first. No soft gradients. Token-driven everything.

What to Feel

Control. Reliability. A tool that does exactly what you tell it. The orange says: energy, not decoration.

What to Drop

The current gear SVG. Generic. No concept. No connection to "skin", "tool", or the token-driven philosophy.

What to Keep

#FF5500 orange. Dark surfaces. The raw, utilitarian energy of the current showcase aesthetic.

Design Direction Selected

After analysing the showcase, the codebase structure, the token architecture, and the audience — one direction wins decisively. Industrial Precision: geometric mark built from the logic of CSS layers, strict grid, zero organic curves. Orange as the only warmth. A wordmark that's as much a code snippet as it is a brand.

Logo Concepts — 3 Directions

Three structurally different ideas. Each is a coherent system, not a sketch. Pick one — it becomes the master mark.

Why This Works
Conceptual depth

3 bars = 3 token layers (primitive, computed, component). The peak-stagger = cascade specificity. Engineers will decode it immediately.

Scales to favicon

The mark works at 16×16px with no degradation. 3 solid bars are readable at any size. No fine detail to lose.

Orange stays the hero

The middle bar is always orange — the "active layer." This preserves the orange DNA without making it a logo blob.

Clear Space Rule

Minimum clear space = height of the orange bar (middle bar) on all four sides. Never place other logos or busy elements within this zone. Minimum digital size: 80px wide lockup, 16px icon mark.

Color System

Built entirely on the existing --ts-accent-h/s/l engine. One primary, two neutrals, three functional. Dark-first. Every swatch maps to a Toolskin token.

Do / Don't
✓ DO
  • Use the orange bar as the sole accent — don't add a second accent color
  • Always maintain the peak-stagger offset in the 3-bar mark
  • Use TOOL + SKIN as a split wordmark (never TOOLSKIN as one weight)
  • Keep the mark dark-first; invert only when necessary
✕ DON'T
  • Rotate, skew, or add gradients to the logo mark
  • Use the old gear SVG — it's been retired
  • Place the logo on busy textured backgrounds without a clear zone
  • Use orange body copy — only headings, accents, and the orange wordmark half

/* Brand identity layer */
--ts-brand-name: 'Toolskin';
--ts-brand-version: 'v1.0.0';
--ts-font-display: 'Space Grotesk', system-ui, sans-serif;
--ts-logo-bar-1: var(--ts-text-primary);
--ts-logo-bar-2: var(--ts-accent);    /* engine layer */
--ts-logo-bar-3: color-mix(in srgb, var(--ts-text-primary) 22%, transparent);

Implementation Path

1. Add the 3 new --ts-logo-bar-* variables to the brand section of toolskin.css.
2. Replace the gear SVG in the showcase <head> favicon and the hero with the 3-bar SVG mark (use <symbol>+<use> for one-source-of-truth geometry).
3. Load Space Grotesk + JetBrains Mono via Google Fonts in extra-styles.css.
4. Update the --ts-font-display assignment in toolskin.css.
5. Replace the hero TOOLSKIN text treatment with the split-weight wordmark.

Everything else — color, surfaces, dark mode, radius — is already in place. The brand is already in the tokens. This proposal just names it and draws it.
